# SV Engine Controlled Examples

These files are synthetic test fixtures. They are not production evidence, real buyer interviews, market findings, price validation, or proof that Provena should build a product.

The examples demonstrate three materially different deterministic outcomes:

- `build_prototype`: every gate passes and the evidence supports only a bounded prototype.
- `validate_further`: buyer and value evidence are missing, so the engine produces a ranked research plan.
- `do_not_build`: customer value remains attractive, but internal operating burden fails G6.

Each output directory contains the complete JSON/Markdown artifact set and run manifest produced by the CLI. Re-running an input under the same rule file yields the same stable business and output hashes; execution IDs and timestamps remain audit metadata.
